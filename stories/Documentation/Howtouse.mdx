# How to use our design system?

Using the UNDP design system is very simple. To use the design system you need to follow these steps and also you need to have an exact component on your application.

### Steps to integrate

- Include the base styling CSS file in your project [https://cdn.jsdelivr.net/npm/@undp/design-system-assets/css/base-minimal.min.css](https://cdn.jsdelivr.net/npm/@undp/design-system-assets/css/base-minimal.min.css).
- Browse the component which you want to integrate.
- Check out the documentation page of the component.
- Copy the HTML of the component in your project.
- Check out the CSS and JS reference section in the document.
- Use the CSS and JS on your project as suggested.
- Follow [Internationalisation](?path=/docs/getting-started-internationalization--docs) guidelines to add support for additional languages.
- Check [Starter template project](https://github.com/undp/design-system-starter-template) for reference implementation and preconfigured boilerplate setup.

### Development

If you want to develop this Design System, follow these steps and you will be ready for further development.

1. Checkout the codebase

```bash
git clone
```

2. Install project dependencies

```bash
npm install
```

3. Runs storybook locally

```bash
npm run storybook
```

4. Build storybook

```bash
npm run build-storybook
```

5. Run this command whenever compiling CSS and JS

```bash
npm run build
```

### Dependencies
(need to be loaded separately)

- Swiper (for Carousels and Galleries) [(https://swiperjs.com/)](https://swiperjs.com/)

### Assets (CSS/JS/Icons) Path

- All the Icons can be found in the **_images_** directory.
- CSS directory at: **_css_**.
- JS directory at: **_js_**.
- HTML can be copied from the canvas tab from the component page.
